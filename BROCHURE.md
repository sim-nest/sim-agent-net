# sim-agent-net

In one line: SIM as a networked host for models and agents -- tools, memory, servers, and work placed across machines.

Roadmap hosts also get `sim-roadmap-exec-core`: one deterministic, effect-free
machine for replaying phase observations, reconciling file images and proofs,
and refusing forged success receipts before an adapter can claim completion.

## What it gives you

A shared runner so any model from any provider plugs in the same way, reusable provider discovery and seat control outside agent assembly, agents that use tools and remember and choose which model answers, skills that expose each ability as a command, an MCP listing so other assistants can discover SIM's tools, OpenAI-compatible and standalone servers that stream replies, remote tables that act local, and a fabric that places work on other machines.
