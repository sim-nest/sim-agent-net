# sim-lib-model-test

This crate owns the open, loadable model-task boundary as well as honest model
candidate identity. `ModelTaskProtocol` prepares a public trial from an immutable
`TaskRevision` and grades terminal output into linked `FacetObservation` rows.
`ProtocolRegistry` loads third-party protocols without central dispatch edits.

Task revisions bind visible input, hidden-oracle identity, parser and grader
revisions, judge calibration, tools, toolchain, seed, and repository closure.
Repository closure sealing fails closed for missing, untracked, dirty, or escaping
files while ignoring unrelated worktree dirt. Generated packs carry deterministic
rank receipts. Deterministic checks remain authoritative; calibrated judges can
widen or withhold evidence but cannot override a deterministic failure.

Pure identity and census records for models tested through SIM provider seats.
The crate hashes canonical, redacted candidate facts into opaque study subject
revisions. It performs no discovery, authentication, transport, or inference.

## Legacy evidence cutover

`import_legacy_batch` is the sole replacement boundary for historical
model-test evidence. A host reads sealed files named by the private migration
manifest and supplies their exact digests and the pinned historical public Git
object. The crate recognizes only the closed manifest, lifecycle, result, task
revision, request revision, depth epoch, SIM result, and cost schemas. The whole
batch is rejected before publication on tampering, unknown schemas, live files,
duplicate source identities, or conflicting observations. Exact repeats are
idempotent and distinct sample identities preserve legitimate repeats.

Classification is explicit and stable: verified evidence may suppress a fresh
trial and enter decisions; partial compatibility/task intent is report-only;
quarantined evidence remains visible but inert. Reports rebuild family-separated
counts, terminal states, exclusions, and resource totals from verified evidence
only. Fresh compatibility intent is executed through SIM independently, and its
execution parity is never folded into import parity.

Deliberate differences from the retired system are part of the contract: sealed
evidence replaces database authority, bounded declared batches replace an
exhaustive default matrix, content-addressed samples replace cohort selection,
and SIM protocols replace Python task execution and the JSON action protocol.
No compatibility command, direct legacy HTTP transport, dual write, or default
rerun remains.
